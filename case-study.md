# STM32-Based Synchronized Dual Encoder Motor Control & RGBW Lighting System

An integrated embedded control system combining encoder-based dual-motor synchronization, multiple communication interfaces, RF remote control, and RGBW lighting control.

[← Back to Projects](./)

---

## Overview

This project combines motor control, wireless remote operation, communication interfaces, and RGBW lighting control within a custom STM32-based hardware platform.

**Microcontroller:** STM32

**My Role:** PCB design, firmware development, motor control algorithm, communication integration, and RGBW control circuit design.

## Key Features

- **Synchronized Dual-Motor Control:** Encoder feedback is used to synchronize two motors.
- **RF Remote Control:** Wireless control of both motor operation and RGBW lighting.
- **Multiple Communication Interfaces:** Wi-Fi, UART, RF, and an Ebyte LoRa module.
- **RGBW Lighting Control:** MOSFET-based RGBW lighting control circuitry.
- **Custom Hardware:** Electronic circuit design and PCB layout.

## Hardware Design & PCB

I designed the electronic circuits and PCB for the integrated control system.

My hardware responsibilities included:

- Electronic circuit design and PCB layout.
- Motor control hardware integration.
- MOSFET-based RGBW lighting control circuitry.
- Integration of the system's communication hardware.

## Firmware & Motor Control

I developed the embedded firmware and motor control algorithm for the STM32-based system.

The motor control approach uses encoder feedback to synchronize the operation of two motors.

## Communication & Remote Control

The system incorporates multiple communication options:

- **Wi-Fi**
- **UART**
- **Ebyte LoRa module**
- **RF communication**

RF remote control provides control of both the motors and RGBW lighting.

## RGBW Lighting Control

The RGBW lighting circuit uses MOSFETs to control the lighting.

I was responsible for designing the MOSFET-based control circuitry and integrating it into the overall hardware platform.
